# 绍宋杀 · 宋金风云录

一款基于穿越历史小说《绍宋》（榴弹怕水 著）背景的三国杀式网页卡牌游戏。单文件 HTML，打开即玩，支持单机热座与线上 P2P 多人对战。

![Tech](https://img.shields.io/badge/tech-vanilla%20JS%20%2B%20PeerJS-gold)
![Platform](https://img.shields.io/badge/platform-web-darkgreen)

## 玩法概述

四人身份局，身份暗抽（与武将阵营解耦——宋将可能是反贼，金将也可能是忠臣）：

| 身份 | 胜利条件 |
|---|---|
| **主公** | 杀光所有反贼与内奸 |
| **忠臣** | 死保主公 |
| **反贼** | 弑杀主公 |
| **内奸** | 最后存活者 |

## 花色系统

每张牌随机分配花色（♠♥♣♦）和点数（A-K），武将有固定花色：

| 花色 | 势力 |
|---|---|
| ♠ 黑桃 | 宋 |
| ♥ 红桃 | 大理 |
| ♣ 梅花 | 西夏 |
| ♦ 方块 | 金 |

**花色共鸣机制**：
- 同花色有其他存活武将时，手牌上限 +1（固定不叠加）
- 同花色武将阵亡时，其余同袍摸 1 牌继承遗志
- 使用【主战】时，每弃一张与自己武将同花色的牌，额外多摸 1 张
- 【死节诏】令所有与主公同花色的存活武将各摸 2 牌

## 特色机制（与普通三国杀的区别）

- **战场牌（地利）**：尧山 / 陕州 / 淮河 / 长社 / 南阳 五种战场牌可抽取、可装备
- **和议 / 主战锦囊**：和议令各方各弃一摸一；主战按弃牌花色共鸣额外摸牌
- **死节诏（限定技）**：忠臣殉国后主公解锁——弃所有牌，同花色武将各摸 2 牌
- **花色共鸣**：替代传统"同阵营"判定，用牌面花色决定敌我共鸣
- **初始手牌按人数**：4 人局 4 张（主公 5 张），3 人局 5 张，2 人局 6 张
- **穿越者先知**：赵玖每回合可窥看下家一张手牌

## 武将（16 名）

**宋**：赵玖（主公）、岳飞、韩世忠、李彦仙、吴玠、张荣
**金**：完颜娄室、完颜兀术、完颜挞懒
**内奸**：秦桧、张俊、万俟卨
**西夏**：李察哥（铁鹞子）、任得敬（河西马场）
**大理**：段和誉（佛国）、高量成（巫蛊/茶马古道）

每名武将带专属技能。

### 四方势力特色

| 势力 | 代表特色 | 技能举例 |
|---|---|---|
| 宋（蓝） | 君臣、忠义、五军联动 | 岳飞尽忠当闪、赵玖先知 |
| 金（红） | 铁骑、南征 | 娄室牙将多出一斩、兀术凿阵 |
| 西夏（棕黄） | 牧场马场、铁鹞子重骑、西夏文 | 李察哥装备战马距离+1伤害+1；任得敬每回合自动披马 |
| 大理（青绿） | 佛国、巫蛊、茶马古道 | 段和誉每回合回血且免疫火烧；高量成巫蛊诅咒他人出斩-1、用粮额外摸牌 |

## 卡牌体系

- **基本牌**：斩 / 避 / 粮
- **锦囊**：决斗、火烧、固垒、连营、离间、勤王、勤王诏、和议、主战
- **装备**：神臂弓（距离+2）、步人甲（防具）、战马（-1马）
- **战场牌**：尧山、陕州、淮河、长社、南阳

## 运行方式

### 单机 / 热座

直接用浏览器打开 `绍宋杀.html`：

- 1 人（3 AI）
- 2 人（2 AI）
- 3 人（1 AI）
- 4 人（全真人同座）

### 线上多人对战

1. 一方点"创建房间"，输入昵称，得到 6 位房间号
2. 其他玩家点"加入房间"，输入昵称和房间号
3. 房主点"开战"

> 联机基于 PeerJS（WebRTC P2P），无需服务器。需要两端能访问 `0.peerjs.com` 信令服务器；严格 NAT 环境可能打不通。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建）
- PeerJS 1.5.x（P2P 联机）
- 单文件交付，CSS / JS 全部内联
