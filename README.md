# 绍宋杀 · 宋金风云录

一款基于穿越历史小说《绍宋》（榴弹怕水 著）背景的三国杀式网页卡牌游戏。单文件 HTML，打开即玩，支持单机热座与线上 P2P 多人对战。

![Tech](https://img.shields.io/badge/tech-vanilla%20JS%20%2B%20PeerJS-gold)
![Platform](https://img.shields.io/badge/platform-web-darkgreen)

## 玩法概述

四人身份局，身份暗抽：

| 身份 | 阵营 | 胜利条件 |
|---|---|---|
| **主公** | 宋 | 杀光所有反贼与内奸 |
| **忠臣** | 宋 | 死保主公，共赴国难 |
| **反贼** | 金 | 弑杀赵玖，覆我大宋 |
| **内奸** | 主和派 | 最后存活者，螳螂捕蝉 |

## 特色机制（与普通三国杀的区别）

- **战场牌（地利）**：尧山 / 陕州 / 淮河 / 长社 / 南阳 五种战场牌可抽取、可装备，据守即得地利——伤害增减、摸牌、回血、免伤等
- **和议 / 主战锦囊**：和议令各方各弃一摸一；主战弃任意牌、每弃一摸一，同阵营额外摸一
- **死节诏（限定技）**：忠臣殉国后主公解锁——弃所有牌，宋军各摸 2 牌，本回合出斩不限次
- **五军联动**：同阵营有其他存活武将时手牌上限 +1（固定不叠加）；同袍阵亡时其他同袍摸 1 牌继承遗志
- **穿越者先知**：赵玖每回合可窥看下家一张手牌

## 武将（12 名）

**宋**：赵玖（主公）、岳飞、韩世忠、李彦仙、吴玠、张荣
**金**：完颜娄室、完颜兀术、完颜挞懒
**内奸**：秦桧、张俊、万俟卨

每名武将带专属技能（如岳飞"尽忠"可任意牌当闪、娄室"牙将"多出一斩、秦桧"议和"挡一次伤害等）。

## 卡牌体系

- **基本牌**：斩 / 避 / 粮
- **锦囊**：决斗、火烧、固垒、连营、离间、勤王、勤王诏、和议、主战
- **装备**：神臂弓（距离+2）、步人甲（防具）、战马（-1马）
- **战场牌**：尧山、陕州、淮河、长社、南阳

## 运行方式

### 单机 / 热座

直接用浏览器打开 `绍宋杀.html`：

- 1 人（3 AI）
- 2 人（2 AI）
- 3 人（1 AI）
- 4 人（全真人同座）

### 线上多人对战

1. 一方点"创建房间"，输入昵称，得到 6 位房间号
2. 其他玩家点"加入房间"，输入昵称和房间号
3. 房主点"开战"

> 联机基于 PeerJS（WebRTC P2P），无需服务器。需要两端能访问 `0.peerjs.com` 信令服务器；严格 NAT 环境可能打不通。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建）
- PeerJS 1.5.x（P2P 联机）
- 单文件交付，CSS / JS 全部内联
